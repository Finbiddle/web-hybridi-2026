A React Native (TypeScript) mobile application built using Expo's `blank` template.

## Exercises
- **Demo: Currency Calculator** – Converts Euros to Pounds.
- **Week 1: Heart Rate Limits** – Calculates target heart rate limits based on age:
  - Lower limit: `(220 - age) * 0.65`
  - Upper limit: `(220 - age) * 0.85`

## Tech & Structure
- TypeScript & Expo (`react-native-safe-area-context`)
- Exercise components are separated into `src/exercises/` and managed via a menu.

## AI Usage
AI (Gemini) was used as a learning tool to help with UI layout, navigation structure, and TypeScript types.
